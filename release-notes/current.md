# Release Notes (Working Draft)

This file is the working draft for the next release. When a version is tagged, this file is renamed to `<version>.md` and a new empty `current.md` is created.

## Changes

- **Every tool call now has a wall-clock budget.** A session wedged for over an hour inside `fetch_page` on a host with an invalid TLS cert: the `spider` crate uses its own HTTP client, so PeakBot's `http:` timeouts never applied, and nothing between that await and the top of the process armed a deadline — a sub-agent lost 150+ completed tool calls. Every tool the model can call (built-in and MCP, gated or not) is now wrapped in a deadline at the single registration seam: 10 min by default, 2 h 5 min for `bash`/`powershell` (above their own `timeout_seconds` clamp), 35 min for `delegate`. An expired call comes back as a normal tool result (`⏱ TIMEOUT: tool …`) the model can react to, not a killed turn, and is logged at `error` level. On top of that, `fetch_page` bounds each fetch attempt at 35 s and reports the URL that never answered (a hung attempt is terminal — a host that swallows the request will not answer 3 s later), and a delegation is bounded at 30 min after which the sub-agent's transcript is still summarised back to the orchestrator as an `INTERRUPTED` handoff instead of being discarded. Fast tools are unaffected — the wrapper is a pass-through. Design: `docs/tool-time-budget-design.md`.
