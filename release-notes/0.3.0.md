# 0.3.0

Minor release. Agent replies in the REPL are now rendered as proper
Markdown — headers, emphasis, code, tables, and nested lists — instead
of raw text dumped into the chat pane.

## ✨ Features

- **Markdown renderer for agent replies.** ATX headers (`# H1` … `###### H6`),
  bold / italic / bold-italic, inline code and fenced code blocks (with
  the closing horizontal rule sized to pane width), and pipe tables
  with column alignment. Engine: `pulldown-cmark` 0.13 with default
  features off (drops the unused `getopts` dep). User input, tool
  output, and system banners stay literal — only the assistant's text
  goes through the renderer.

- **Lists: bullets, numbered, nested, task-list.** Unordered items use
  a styled `•` marker, ordered items honour `Tag::List(Some(n))` start
  numbers (`5.`, `6.`, …), nesting indents 2 cells per depth, and
  GFM task-list checkboxes (`[ ]` / `[x]`) render verbatim. Inline
  emphasis and inline code inside items are preserved. Trailing blank
  line is emitted only when the **outermost** list closes, so nested
  groups don't grow gaps between every level.

## 🔧 Internals

- `MessageRenderer` trait grew a `width: u16` arg so renderers can wrap
  to the actual pane width; `Fingerprint` gained a matching `width`
  field so `ChatRenderCache` invalidates rendered `Line`s automatically
  on terminal resize — no special `clear()` path needed.
- New `chat_pane_content_width(main_width, select_mode)` helper accounts
  for both chat-block borders **and** the 1-cell scrollbar carve-out.
  Previously the closing rule of fenced code blocks was being eaten in
  normal mode while accidentally working in F4 select mode.
- All width math now routes through `unicode-width` display cells (now
  a direct dep, was transitive via ratatui) so emoji / CJK columns
  align to ratatui's own layout metric.

## 🐛 Drive-by fixes

- **Flaky `alignment_right_pads_left` test pinned.** The body-line
  selector used to anchor on `'7' && !"7 "`, which matched the agent
  prefix line at any sec / min / hour ending in 7
  (e.g. `[16:35:37] 🤖 Agent:`). Now anchors on `│` (the table glyph),
  which only appears in actual table rows.
