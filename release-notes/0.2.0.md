# 0.2.0

Minor bump rolling up conversation-management improvements and the
documented commit gate.

## ✨ Highlights

- **`/conversations` overhaul.** Index-based addressing replaces UUIDs
  for `/load`, `/delete`, and `/export`. UUIDs still accepted as a
  fallback. The legacy `/history` command is retired.
- **Per-conversation stats persistence.** `/load` now restores tokens,
  cost, and API-call counters from the saved conversation, so the
  status bar reflects the loaded session instead of the previous one.
- **Documented pre-commit gate.** `agents.md` now formalises the
  mandatory `cargo fmt && cargo clippy --all-targets --all-features --
  -D warnings && cargo test` sequence.

## 🐛 Fixes

- `StateManager::save_conversation` self-deadlock removed (held a
  `MutexGuard` across the if-let body, then re-locked the same
  non-reentrant `std::sync::Mutex`). Pinned by a regression test.
- `/load` no longer leaves the previous session's stats visible in the
  status bar.
- `sync_stats_to_ui` no longer holds `stats.lock` across `state.write`,
  closing an A→B vs B→A deadlock pinned by an atomic-watchdog test.
