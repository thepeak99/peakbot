# PeakBot 0.9.0

## Changes

- Fixed the manual `/compact` command showing the generic "thinking" spinner label instead of "Compacting context...". The auto/in-loop and memory.md compaction paths already set a status message; the manual `/compact` handler omitted it, so the working-spinner fell back to its default label. It now emits the same "Compacting context..." status as the automatic path.
- Fixed conversation titles silently never generating on the Anthropic provider with non-Claude model names (e.g. gateway models like `minimax/MiniMax-M3`). The auto-title model (shared with context compaction) is built via rig's Anthropic agent, which requires `max_tokens` to be set — rig errors *locally* before any HTTP call when it's unset, and its per-model default is `None` for any non-Claude name. The compaction-model builder now sets `max_tokens` explicitly from the provider config, so both auto-titling and compaction work on Anthropic gateway models. (Compaction summaries were affected by the same root cause.)
- Added a `--stdio` frontend (#54). `peakbot --stdio` runs an NDJSON stdin/stdout View for IDE integrations (e.g. the VSCode extension) instead of the terminal UI, reusing the same agent, providers, tools, skills, MCP servers, and conversation persistence. Absorbed from the standalone `peakbot-stdio` crate into `src/ui/stdio` — no new crate or binary; logs are routed to stderr so stdout stays a clean protocol channel.
- Fixed compacted conversations breaking on `/load` (#59). Context compaction now persists the per-message `compacted` flag and the inserted summary, so a conversation compacted in a previous session reloads with its compacted state intact instead of resurrecting the full history and forcing manual re-compaction.
- Fixed the agent reaching for bash on PowerShell hosts (#82). The detected shell is now surfaced as a `**Shell**:` line in the system prompt's environment block, derived from the same `ShellKind` used to register the shell tool. On a PowerShell host the line names the `powershell` tool and instructs PowerShell syntax, overriding the bash-centric examples baked into the static prompt — so the model stops emitting `grep`/`sed` and getting confused when nothing runs.
- Fixed CI failing on every release commit because the `chat_welcome` REPL snapshot hardcoded the package version (`PeakBot v0.8.0`). The `release-bump` step rewrites `CARGO_PKG_VERSION`, which changed the rendered banner and broke the snapshot. The welcome snapshot now runs through an insta regex filter that normalizes any semver in the banner to a fixed `vX.Y.Z` token, decoupling the snapshot from the version. Enabled insta's `filters` feature to support this.
